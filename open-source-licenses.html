Third-Party Software & Licences

Software notices, component rights and asset ownership.

Version 2026-10-24 · Updated 24 October 2026

On this page

  1. 1. Read software notices
  2. 2. Main component families
  3. 3. App and website assets
  4. 4. Requests and corrections

REATTAIN incorporates third-party software. Its components remain subject to their own copyright notices and licence conditions. The REATTAIN EULA does not replace or restrict rights granted by those licences.

1. Read software notices

In the app, open Settings → Legal → Open-source licences to read the licence registry bundled with that installed build. A downloadable Flutter/package notice snapshot is provided with these pages. Release builds can include different package/native components, so the installed notices and the relevant component licence apply.

2. Main component families

The project uses Flutter/Dart, Riverpod, GoRouter, Drift/SQLite, Firebase/Google Sign-In, camera and Google ML Kit pose detection, Android platform libraries, notifications, charting, billing and other utility packages. These examples are not an assertion that every component uses the same licence or that proprietary provider terms are open-source licences. Firebase, Google Play and other hosted services also have their own service/privacy terms.

Font notices: Sora licence · Manrope licence.

3. App and website assets

Third-party names and marks belong to their respective owners. Original REATTAIN branding and text belong to their lawful owner; a licence for a code package does not automatically license its logos, screenshots, fonts, reading passages, music, photos or other assets. These policy pages use locally hosted Sora and Manrope fonts under the SIL Open Font License, with system-font fallbacks. Their licence notices are bundled with the font files. Rights to distributed content must be documented separately.

4. Requests and corrections

If a component licence requires source-code availability or an additional notice, that requirement continues to apply. Contact monkeymariners@gmail.com with the component and app version for a notice/source request or a correction. See Copyright & Intellectual Property for other infringement reports.
