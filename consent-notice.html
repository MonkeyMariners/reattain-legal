Consent & Tracking Notice

Separate choices for permissions, backup, accounts and publication.

Version 2026-10-23 · Updated 23 October 2026

On this page

  1. 1. Local use and age band
  2. 2. Feature permissions
  3. 3. Optional account and backup
  4. 4. Publication and social features
  5. 5. Analytics, ads and website storage
  6. 6. Withdrawal, changes and requests

This notice explains which choices are independent. Accepting app terms does not authorize every processing activity. See the Privacy Policy for categories, recipients, legal bases and rights.

1. Local use and age band

You can use focus tools without Google sign-in or Firebase history backup. The app asks for a locally saved age band. Under-13s are not supported. Ages 13–17 use local tools only; the app does not ask a child to pretend that a parent’s permission has been verified. Online features require age 18+ in this release.

2. Feature permissions

Accessibility has a separate prominent disclosure with “Not now” and an affirmative continue action before Android Settings opens. Camera, phone, notification, usage, overlay, Do Not Disturb and battery access serve different purposes. Grant only the permissions for features you want. Revoke them in Android Settings. Refusing an optional permission limits the relevant feature, not access to all local tools.

3. Optional account and backup

Google sign-in authenticates an eligible adult; it is not the same as choosing cloud history backup. Backup is off until you switch it on in Settings after reading the explanation. It sends the limited session, challenge and progress fields in the privacy notice to Firebase. Switch it off in the same location to stop new requests. Withdrawal does not delete an existing cloud copy or undo a completed transfer; use the deletion request.

Your Android system backup can operate separately under device settings. An app backup toggle does not control Google/device backup or transfers to a replacement phone.

4. Publication and social features

Social tools are disabled in this release. In a version that offers them, publishing a profile shares the fields explained on the Friends screen. Existing published profiles and room/member data can be read by authenticated users under the current rules; do not treat them as friend-only or private. Request deletion of remaining server records through our contact. Removing one record is not withdrawal from every other feature.

5. Analytics, ads and website storage

Automatic Analytics collection and Crashlytics uploads are disabled in this release; there is no optional diagnostics opt-in UI. There is no advertising SDK, personalized advertising or marketing-cookie system. These static pages set no app-managed cookies or local storage and load no remote fonts. There is consequently no non-essential site-cookie choice to enable today. Hosting and requested online services still process network data. See Cookie & Website Storage Policy.

6. Withdrawal, changes and requests

Use the relevant setting to stop optional access, and contact us for help, copies of records or a privacy complaint. We do not charge you or remove unrelated local tools for refusing optional processing. If a new optional purpose is introduced, its notice and consent controls must be provided before it starts. Merely reading a policy or continuing to use the app does not provide new consent.

Clear information. Your choice.
